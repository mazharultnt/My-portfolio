# My Portfolio Website

My first personal portfolio, built with plain HTML, CSS and JavaScript. No frameworks and no build step.

## Sections

- Hero with a short intro
- About me
- Skills (tabs for Languages, Frameworks and Tools)
- Projects (filter by type)
- Contact form with validation

## How to run

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Change the content

- Skills and projects are listed in `js/projects.js`
- Colors are at the top of `css/style.css`
- Put pictures in the `images/` folder (see the image guide for file names)

The contact form only checks the fields. It does not send the message anywhere because this is a practice project.

Built with HTML5, CSS3 and vanilla JavaScript.
